# CLI & Tooling Reference

The `dap` binary provides tools for executing code, inspecting lexer tokens, visualizing the Abstract Syntax Tree (AST), and cross-compilation.

---

## Command Overview

```text
Usage:
  dap [flags] [file]

Commands & Options:
  dap                       Start interactive console (REPL)
  dap <file.dap>            Execute a DAP source file (Tree-Walking Interpreter)
  dap --compile <file.dap>  Compile AST to lightweight bytecode disassembly
  dap --vm <file.dap>       Execute a DAP source file via Bytecode Virtual Machine
  dap -o <dest.dapb>        Specify output file for compiled bytecode
  dap --version, -v         Check DAP version and verify GitHub updates
  dap --update, -u          Automatically update DAP to latest release
  dap <file.dap> --show-bytecode Show disassembled bytecode during execution
  dap <file.dap> --show-token    Inspect token stream from the lexer
  dap <file.dap> --show-ast      Inspect the parsed Abstract Syntax Tree
  dap <file.dap> --show-ast-json Inspect AST in JSON format
  dap --help, -h            Show help and usage information
```

---

## 1. Running Source Files

To execute any `.dap` source file with the standard tree-walking interpreter:

```bash
dap program.dap
```

To execute via the high-performance **Bytecode Virtual Machine (VM)**:

```bash
dap --vm program.dap
```

---

## 2. Compiling AST to Bytecode (`--compile`)

To compile the Abstract Syntax Tree into lightweight symbolic bytecode:

```bash
dap --compile program.dap
```

To save the disassembled bytecode to a file:

```bash
dap --compile -o program.dapb program.dap
```

---

## 3. Inspecting Tokens (`--show-token`)

To inspect how the DAP lexer tokenizes your program, use the `--show-token` flag:

```bash
dap program.dap --show-token
```

---

## 4. Inspecting the AST (`--show-ast`)

To view the hierarchical Abstract Syntax Tree generated by the parser:

```bash
dap program.dap --show-ast
```

---

## 4. Cross-Compiling for Other Platforms

Since DAP is written in pure Go without CGO dependencies, you can compile it for any target operating system directly from your machine.

### Compile for Linux (amd64)
=== "Windows (PowerShell)"
    ```powershell
    $env:GOOS="linux"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o dist/dap-linux-amd64 .
    ```

=== "macOS / Linux (Bash)"
    ```bash
    GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -ldflags="-s -w" -o dist/dap-linux-amd64 .
    ```

### Compile for macOS (Apple Silicon arm64)
```bash
GOOS=darwin GOARCH=arm64 CGO_ENABLED=0 go build -ldflags="-s -w" -o dist/dap-darwin-arm64 .
```

### Compile for Windows (amd64)
```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags="-s -w" -o dist/dap-windows-amd64.exe .
```
